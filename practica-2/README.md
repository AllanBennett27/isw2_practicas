\# Práctica 2 - Flujo Profesional



\## Ingeniería de Software 2



\### Descripción

Esta práctica tiene como objetivo implementar

un flujo de trabajo profesional utilizando

Git y GitHub.



\### Objetivos

\- Crear y administrar ramas.

\- Realizar commits.

\- Crear Pull Requests.

\- Aplicar revisiones de código.

\- Integrar cambios mediante merge.



\### Herramientas utilizadas

\- Git

\- GitHub

\- GitHub Desktop

\- Visual Studio Code



\### Flujo de trabajo

1\. Crear una rama de desarrollo.

2\. Realizar modificaciones.

3\. Guardar los cambios mediante commits.

4\. Publicar la rama en GitHub.

5\. Crear un Pull Request.

6\. Solicitar una revisión cruzada.

7\. Realizar el merge hacia main.



\### Conclusión

El uso de Git y GitHub permite organizar

el desarrollo de software, mantener un

historial de cambios y facilitar el

trabajo colaborativo.
